# Student Groups

A small page for splitting a class into project teams (مجموعات الطلاب).

- Each team has a card listing its current members.
- A student picks a team, enters their name and joins; the same name can't join a team twice.
- Students can leave their team to switch.

Arabic, right-to-left. Stack: PHP, MySQL, vanilla JavaScript (fetch API).

## Run locally (XAMPP)

1. Put the folder in `htdocs/Sensors`.
2. Open `http://localhost/Sensors/`. `db.php` creates the `groups_system` database and `members` table on first run (or import `database.sql`).
3. To change the teams, edit the team cards in `index.html`.
